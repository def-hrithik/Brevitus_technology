## 📖 About The Project

**Brevitus Technology** is a dynamic web platform built to showcase professional courses, industry-level internships, and upcoming tech events. Developed as a freelance project, it focuses on delivering a seamless user experience with modern UI/UX principles, smooth animations, and a highly responsive design. 

The platform allows users to explore current offerings, view featured past projects, read testimonials, and stay updated with the latest from Brevitus Technology.

---

## ✨ Key Features

- **🎓 Courses Directory**: Explore available professional training programs and modules.
- **💼 Internship Opportunities**: Dedicated portals for browsing and applying to tech internships.
- **📅 Events Dashboard**: Track past and upcoming technical events and bootcamps.
- **⚡ Interactive UI**: Built with modern animation libraries for a highly engaging user experience (including typewriter effects, dynamic background boxes, and dot grids).
- **📱 Fully Responsive**: Optimized for seamless viewing across all devices, from mobile phones to large desktop monitors.

## 🛠️ Tech Stack

This project was crafted using cutting-edge web technologies:

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** Framer Motion & Custom UI Components
- **Code Quality:** ESLint & Prettier

## 💻 Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have Node.js and npm installed on your machine.

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/def-hrithik/Brevitus_technology.git
   ```
2. Navigate into the project directory
    ```
    cd Brevitus_technology
    ```

3. Install the dependencies
    ```
    npm install
    ```

4. Start the development server
    ```
    npm run dev
    ```

5. Open http://localhost:3000 with your browser to see the result.
